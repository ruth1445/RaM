What the repo computes

The implementation compares direct answering with chain-of-thought, scores their relative utility, subtracts token cost, then chooses a strategy.

01

Question

Take a task and its gold answer.

02

Direct path

Estimate the gold answer log-probability without extra reasoning.

03

CoT path

Estimate the gold answer log-probability after a reasoning trace.

04

Compute VOC

Utility = CoT logprob − direct logprob. Cost = γ × reasoning tokens.

05

Choose

VOC > 0 selects CoT. Otherwise, answer directly.

A train leaves at 2 PM and arrives at 5 PM. How long is the trip?
DirectThe train leaves at 2 PM and arrives at 5
Chain-of-thoughtThe train
Gold answer: 3
Direct reasoningLower token cost. Chosen when extra computation does not pay off.
Chain-of-thoughtHigher computation cost, justified only when expected utility increases enough.
Value of ComputationVOC = utility − cost, the decision signal used by this replication.

The interactive values above are illustrative. The repository currently does not include the generated outputs/voc_scored.json file that the Streamlit explorer expects, so measured VOC scores are not shown here.
