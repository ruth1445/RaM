Value of Computation · adaptive reasoning

When is thinking worth it?

This replication treats reasoning as a resource-allocation problem. A model should spend extra tokens only when the expected gain in answer quality exceeds the cost of computation.

Decision rule

Your scorer computes the same quantity for every example, then picks one of two reasoning modes.

VOC = (log pCoT(y) − log pdirect(y)) − γ · |z|
VOC > 0
Use chain-of-thought
VOC ≤ 0
Answer directly

Method

What the replication computes

A compact view of the implemented pipeline, from a question and gold answer to a metareasoning choice.

01

Generate paths

Produce direct and chain-of-thought candidates.

02

Score direct

Compute gold-answer log-likelihood without extra reasoning.

03

Score CoT

Compute the same target after the reasoning trace.

04

Price tokens

Cost = γ × number of reasoning tokens.

05

Select strategy

Positive VOC chooses CoT; otherwise answer directly.
